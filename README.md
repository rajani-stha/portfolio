# Daya Sagar — Portfolio (React + Vite)

## Run it
```bash
npm install
npm run dev      # local dev server
npm run build    # production build in /dist
```

## Where to edit
- `src/data/content.js` — all text: projects, skills, experience, email
- `src/components/*` — one component per section
- `src/styles.css` — original CSS, unchanged (colors are CSS variables at the top)
